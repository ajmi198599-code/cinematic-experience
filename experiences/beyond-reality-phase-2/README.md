# BEYOND REALITY — Phase 02: The Deep Blue

An immersive, bilingual cinematic website. This chapter takes visitors from the glowing Phase 01 portal through a luminous transition into a responsive underwater world.

## What works
- Enter the portal for a cinematic light-tunnel transition.
- Enjoy an animated original SVG whale with layered lighting and particles drawn using HTML Canvas.
- Tap/click anywhere on the open water to make fading ripple rings.
- Switch between Arabic and English.
- Optional browser-generated ambient audio, off by default.
- Return to the initial scene at any time.
- Mobile layouts, reduced-motion support, pause animations in background tabs, no external assets or trackers.

## Implementation and testing
Self-contained HTML, CSS, SVG and vanilla JS; no dependency installation needed. Local Chromium interaction tests at 360, 390, 430, and 1440 pixel widths checked navigation, language toggle, ripples, overflow and JavaScript errors.

## Hosting
Deploy this folder as a static website with Vercel Framework Preset: Other. Set Root Directory to `experiences/beyond-reality-phase-2`. A standalone Phase 2 preview should not replace the existing Phase 1 or concept report sites. The site is a creative prototype; no ecommerce or personal-data collection is included.
