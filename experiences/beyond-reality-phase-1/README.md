# BEYOND REALITY — Phase 01: The Arrival

A polished, responsive cinematic landing page with a luminous interactive portal, canvas star particles, pointer parallax, dramatic gateway transition, and a second cinematic scene.

## Features
- English + Arabic (RTL) language switch
- Animated portal: **STEP INSIDE / ادخل البوابة** to travel, **RETURN TO ARRIVAL** to return
- Atmospheric light effects, small canvas star field, low-bandwidth experience
- Optional ambient synthesised sound, always **off by default**
- Accessibility: reduced-motion support, visible focus rings, Escape key return
- Works on iPhone and desktop without dependencies, external images, third-party frameworks, or external requests

## Local development
Open `index.html` in a browser. No installation or build required.

## Deployment
Use a **separate** Vercel project with Root Directory `experiences/beyond-reality-phase-1`, Framework Preset **Other**. Do not attach to the Vercel project that hosts the interactive concept lab.

## Scope
Only **Chapter 01: The Arrival** is implemented. Chapter 02: The Deep Blue is a coming-soon teaser. The interactive concept report remains unchanged.
