# BEYOND REALITY — Complete Cinematic Journey

A mobile-first interactive website containing the five planned creative chapters. Designed as a **concept showcase**; this is not a real shop.

## Visitor journey

1. **The Arrival** — animated luminous portal and an interactive entrance.
2. **The Deep Blue** — underwater rays, procedural bubbles and an animated whale; touch ripples.
3. **Your Universe** — choose and explore **Inferno (Fire), Eden (Nature), or Orbit (Space)**. Each world has original vector artwork, procedurally drawn particles and tap/click bursts.
4. **The Finale** — cinematic orb, a closing message and options to explore again.
5. **Virtual Gallery** — an illustrative mall hallway with **Tech, Market, and Style** demo shops; a working **demo basket** with add/clear interactions.

The website includes Arabic/English switching, keyboard-friendly navigation, a muted-by-default browser-generated ambient sound toggle, mobile layout and reduced-motion support. All artwork is generated from local CSS, Canvas and inline SVG; **no external photos, fonts, product APIs, analytics, payment providers, or dependencies**.

## Try locally

Open `index.html` in a normal web browser, or serve this directory through any static web server. No build command or packages are required.

## Publish on Vercel

Choose a new static project and set **Root Directory** to `experiences/beyond-reality-complete`; Framework Preset: **Other**. Keep the existing Phase 1 and Phase 2 deployments unchanged.

## Before a commercial launch

The gallery is for UX validation only. All sample names and catalogue entries are fictional. There is **no real ordering, checkout, inventory or payment processing**. For a commercial version, replace drawings and samples with properly licensed, genuine product media; integrate a managed catalogue/inventory backend, payment provider, legal pages, customer service, taxation and delivery workflows; then test conversion and accessibility on real devices.

## Testing

Browser interaction walkthroughs cover the portal, underwater-to-hub navigation, each world, the finale and virtual gallery, with viewport checks at mobile and desktop widths. These browser tests are not equivalent to real-device performance certification.
